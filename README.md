## About Me

I'm a college student who picked up programming roughly a year ago and hasn't stopped since. What started as curiosity about how software works has turned into something I'm genuinely driven by.

My journey so far has been rooted in **understanding how things actually work** — not just copying syntax, but learning why Java is built the way it is, how memory structures behave, and what makes clean code clean. That foundation is something I'm proud of, even at this early stage.

Right now, I'm pushing in three directions at once: **strengthening my DSA**, **growing into full-stack web development**, and slowly exploring **game development** on the side. I know I'm early in the journey — and that excites me more than it intimidates me.

## What I've Learned So Far

I didn't start with web pages or tutorials — I started with **Java and core programming concepts**. That meant learning OOP properly, understanding how data structures work under the hood, and building the kind of logical thinking that makes you a better developer regardless of language.

```
Java  →  OOP · Functions · Objects · Arrays
        Data Structures: Stacks · Queues · Linked Lists
        Algorithm thinking · Problem decomposition
```

From there, I moved into **web fundamentals** — HTML, CSS, and Bootstrap — learning how to bring things to life in the browser and understand the structure of the web.

```
Web   →  HTML5 · CSS3 · Bootstrap
         Responsive design · Component layout · Styling systems
```

And I've started growing into **JavaScript** — the language that bridges everything together.
